# 업무 내비게이터

업무별 체크리스트·마감일·보고서·서식·법령 자료를 한곳에서 관리하는 **단일 HTML 업무 도우미**입니다.
설치나 서버 없이 브라우저로 파일을 열면 바로 동작하며, 외부 CDN 없이 `vendor/` 폴더의 로컬 파일만 사용합니다(오프라인 동작).

- 현재 버전: **v1.4.0** (2026-10-10)

## 파일 구성

| 파일 | 용도 |
| --- | --- |
| `index.html` | **배포용.** 사내 보안 정책상 AI 연결 설정(외부 AI·API 키 입력 UI)을 막아 둔 버전 |
| `ai_test .html` | **관리자 테스트용.** AI 연결 설정이 열려 있는 버전 (제목에 `[TEST - 관리자 전용]` 표시) |
| `내부망_점검.html` | 내부망 PC에서 폴더 저장·자료 유지가 되는지 확인하는 **점검 파일** (아래 「내부망 PC 점검」 참고) |
| `vendor/` | PDF.js(`pdf.min.js`, `pdf.worker.min.js`), Mammoth(Word 문서 읽기), Pretendard 글꼴 |

> 두 HTML 파일은 **AI 연결 설정 화면의 노출 여부만 다르고 나머지는 모두 같습니다.**
> 기능을 고칠 때는 **두 파일에 똑같이 반영**해야 합니다.
> (참고: `ai_test .html`은 파일 이름의 `.html` 앞에 공백이 하나 있습니다.)

차이가 나는 곳은 AI 연결 설정 영역의 두 블록뿐입니다.

- `index.html`: 보안 정책 안내 블록은 보이고, AI 입력 UI 블록은 `display:none`
- `ai_test .html`: 안내 블록은 `display:none`, AI 입력 UI 블록은 보임

## 실행 방법

- 화면은 **최소 1280×680**(업무 절차 패널을 접으면 900×680)으로 보이도록 되어 있습니다. 브라우저 창이 이보다 작으면 배치를 바꾸지 않고 화면 전체에 가로·세로 스크롤이 생깁니다.

1. HTML 파일과 `vendor/` 폴더를 **같은 위치**에 둡니다.
2. `index.html`(또는 `ai_test .html`)을 Chrome·Edge 같은 최신 브라우저로 엽니다.

`vendor/`가 없으면 글꼴·PDF 미리보기·Word 문서 읽기가 동작하지 않습니다.

## 데이터 저장

- 업무 자료는 프로그램 파일이 아니라 **브라우저 저장 공간(localStorage / IndexedDB)** 에 저장됩니다.
  그래서 HTML 파일을 새 버전으로 바꿔도 자료는 그대로 남습니다.
- 다른 브라우저나 다른 PC에서는 자료가 보이지 않으므로, **설정 → 백업 및 복원**으로 백업 파일을 만들어 옮기세요.
- 브라우저 사용 기록·사이트 데이터를 지우면 자료가 사라질 수 있으니 정기적으로 백업하세요(백업 알림 주기 설정 가능).

## 주요 기능

- **업무 관리**: 상태 탭(전체·진행중·레퍼런스·처리완료·보관함), 폴더, 끌어다 놓기로 이동, 휴지통
- **체크리스트**: 「단계 + 할 일」 구조, 건너뛰기·조건부 항목, 「해당 없음」 처리, 항목별 마감일
- **재사용 업무 / 레퍼런스**: 끝난 업무를 깨끗한 사본으로 등록해 다음에 복사하여 시작
- **보고서**: 보고서 작성·관리
- **서식·문서함**: 서식·예시 공문 보관(HWPX·PDF·Word 미리보기)
- **법령·매뉴얼 자료실**: 법령·지침 보관 (AI 연결 시 답변 참고 자료로 활용)
- **날짜 선택 창**: 모든 날짜 칸에서 공통 — 빠른 선택(오늘·내일·금요일·다음 주 월·이달 말·🏁 업무 마감 등), 주말·공휴일(설·추석·부처님오신날은 2025~2030년, 대체공휴일 자동 계산, 선거일·임시공휴일 제외) 빨간 글씨, 다른 마감(점)·업무 마감(🏁) 표시, 마우스를 올리면 D-n·근무일 수·「업무 전체 마감보다 늦음」 경고. 키보드: 방향키·PageUp/Down·Enter·Esc
- **일정 보기**: 상단 [일정](진행 중인 모든 업무) 또는 업무 화면 [일정 보기](그 업무만) — 항목 마감을 월 달력으로, 오른쪽에 「기한 지남 + 이번 주 할 일」. 항목을 다른 날로 끌어 놓으면 마감일 변경, 누르면 그 항목으로 이동(협업 단계 마감은 협업 창에서 변경)
- **알림**: 마감일 시작 배너, 헤더 종 아이콘의 인앱 알림센터, (권한이 있으면) OS 데스크톱 알림
- **공유 / 내보내기·가져오기**: 업무 패키지·템플릿 패키지
- **통계 대시보드**, 다크 / 라이트 모드
- **AI 기능**(Gemini·ChatGPT·Claude): 체크리스트·보고서·길잡이 가이드 생성 — `ai_test .html`에서만 연결 설정 가능

## 체크리스트 사용법

- **새 업무 만들기**(사이드바 [새 업무 만들기] → 체크리스트 생성): ① **이름** → ② **절차** → ③ **자료(선택)** 3단계입니다. 이름만 정하면 시작할 수 있고, 마감일·폴더는 일하면서 정합니다.
  - ② 절차: Enter로 다음 항목, Tab으로 할 일(다시 누르면 단계로). 할 일은 위 단계와 선으로 이어지고, 단축키 줄은 목록 위에 늘 보입니다. 매뉴얼·공문에서 복사한 절차를 붙여 넣으면 번호·기호·들여쓰기로 단계와 할 일을 나누고, ※·설명 줄은 업무팁으로 넣습니다. [바로 시작]으로 자료 없이 시작할 수 있습니다.
  - ③ 자료: 「참고 자료(관련 법령·업무 매뉴얼)」에서 [📎 첨부 자료](PDF)와 [⚖ 법령·매뉴얼]을, 「항목별 자료」에서 항목마다 [💡 업무팁] [📄 서식]을 넣습니다. 넣으면 ✓·개수로 바뀝니다. 모두 선택이고 [시작하기]를 누르면 업무 화면이 열립니다. 본보기(레퍼런스)는 업무를 마친 뒤 「레퍼런스로 등록」으로 만듭니다.

- **체크**: 줄 왼쪽의 번호·체크 상자 부분(넓은 띠)을 누릅니다.
- **제목을 누르면** 줄 아래로 조치결과 입력칸과 빠른 버튼(📝 조치결과 자세히 · 💡 업무팁 · 📄 서식 · ⊘ 해당 없음으로 빼기, 터치 화면에서는 ✨ 길잡이도)이 펼쳐집니다. 버튼을 누르면 그 탭이 열린 창이 뜹니다(조치결과·업무팁·서식). 같은 제목을 다시 누르면 닫힙니다.
- **줄 모양**: 오른쪽에 폭이 고정된 칸(할 일 · 마감 · 점 3자리)이 있어 모든 줄에서 세로로 맞습니다. 점은 조치결과(보라)·업무팁(주황)·서식(초록) 순서로 늘 같은 자리에 있습니다. 진행중 단계는 번호가 보라 동그라미로 표시됩니다(업무 절차 패널과 같은 「진행중」 색, 파랑은 버튼·링크에만). 협업 담당과 건너뛰기 버튼은 제목 아래 둘째 줄에 있고, 없으면 한 줄입니다. 건너뛰기 버튼이 3개 이상이면 2개만 보이고 나머지는 「⤼ +n」을 눌러 고릅니다. 버튼 이름은 길게 써도 되지만(최대 50자) 버튼에는 앞 8자까지만 「…」로 보이고, 마우스를 올리면 전체 이름이 보입니다.
- **길잡이**: 줄에 마우스를 올리면 오른쪽에 「✨ 길잡이」 버튼이 나타납니다. 그 항목(하위 할 일 포함)의 업무팁·서식·법령을 한 화면에 모아 봅니다. 업무팁이 있으면 주황 점, 서식이 있으면 초록 점이 붙고, 주황 점에 마우스를 올리면 업무팁 첫 줄이 보입니다. 업무 절차 패널은 「단계 → 할 일 목록 → 업무팁 상자」 순서입니다. 단계를 시작할 때는 단계 팁과 지금 차례 할 일의 팁을 함께 보여 주고, 할 일을 하나라도 끝내면 단계 팁은 「▸ 단계 업무팁」 한 줄로 접히고 지금 할 일의 팁만 보입니다. 긴 팁은 몇 줄까지만(둘이면 3·4줄, 하나면 7줄) 보이고 「… 전체 내용은 ✨ 길잡이에서」로 이어집니다.
- **해당 없음 고르기**: 체크리스트 위 「해당 없음 고르기」로 여러 항목을 한 번에 뺍니다. 단계를 고르면 할 일도 함께 고르고, Shift+클릭으로 여러 개, 위쪽 칸에서 항목을 찾을 수 있습니다. 전체화면 버튼도 있습니다. 항목 하나만 뺄 때는 줄의 빠른 버튼 「⊘ 해당 없음으로 빼기」를 씁니다(항목 창 위의 버튼은 없앴습니다).
- 줄을 마우스 오른쪽으로 누르면 해당 없음 같은 메뉴가 나옵니다. 해당 없음으로 뺀 항목은 줄의 [되살리기]로 되돌립니다.
- **건너뛰기**: 미리 만든 버튼(예: 「자체 종결」)은 줄에 보이며 누르기만 하면 됩니다. 버튼을 만들려면 [체크리스트 편집] → 항목의 **[⚙ 설정]** → 「＋ 건너뛰기 버튼 만들기」 → 버튼 이름(예: 자체 종결)을 적고, 체크리스트 위에서 **건너뛸 항목을 바로 체크**한 뒤 [저장]합니다(단계를 고르면 할 일도 함께). 한 항목에 버튼을 여러 개 둘 수 있고, 같은 메뉴에서 버튼마다 고치기·지우기를 합니다. 기준 항목 자체를 빼려면 일하는 화면의 「해당 없음으로 빼기」를 씁니다.
- **편집 화면** (들어가면 맨 위부터, 나오면 일하던 자리로, Tab 또는 줄의 ⇥·⇤ 버튼으로 상위↔하위):  ⤼ 이름 = 건너뛰기 버튼(여러 개면 「자체 종결 외 1」) · ◌(보라 점선) = 다른 버튼이 이 항목을 건너뛸 수 있음 · 점 = 서식(초록)·업무팁(주황) 있음. 항목 추가·삭제·설정은 오른쪽 끝 ⚙ 메뉴(또는 마우스를 올리면 나오는 ＋·🗑).
- **조치결과·업무팁 상위·하위 쓰기**: 입력칸 위 기호 줄에서 보고서식 `□ ○ - ·` 또는 공문식 `1. 가. 1) 가)`를 누르면 그 줄 앞에 붙습니다. Enter를 누르면 다음 줄에 같은 기호가 이어지고(번호는 다음 번호), 기호만 있는 빈 줄에서 Enter를 누르면 목록이 끝납니다. ⇥·⇤ 버튼(키보드 Tab·Shift+Tab)으로 단계를 바꾸면 기호도 따라 바뀝니다. 평범한 글자라 한글·공문에 그대로 붙여 넣을 수 있습니다.
- **마감 카드**(업무 화면 왼쪽): D-n·날짜(요일)·근무일 수·생성일→마감 기간 막대. 진행이 기간보다 30% 넘게 늦으면 ⚠. 카드를 누르면 날짜 선택 창이 열립니다.
- **왼쪽 메뉴 아이콘**: 체크리스트 편집(연필)·업무 분담(사람)·AI 기안·출력(프린터)·내보내기·삭제(휴지통)에 상단 메뉴와 같은 가는 선 아이콘. 평소 회색, 마우스를 올리면 파랑, 삭제는 빨강.
- 끌어서 스크롤하거나 글자를 고르거나 체크 직후 빠르게 다시 누른 경우에는 아무것도 열리지 않습니다.

## 협업 (오프라인 · 내부 메신저로 파일 주고받기)

- **관리자 화면 보기 선택**: 체크리스트 제목 줄의 [전체] [내 할 일] [맡긴 일 ▾]. 「전체」에서는 내 단계는 펼치고, 맡긴 단계(회신 대기·보내기 전)는 점선 한 줄 「⏳ 02 현장 점검 · 할 일 2 — 김철수 · 회신 대기 · D-4」로 잠가 둡니다(누르는 동작 없음, 마우스를 올리면 그 단계의 할 일 제목이 한 줄에 하나씩 말풍선으로, 기한이 지나면 빨강). 「맡긴 일 ▾」에서 회신 대기·회신 받음·사람별로 골라 그 항목만 펼쳐 회신을 검토합니다. 고른 보기는 업무마다 기억합니다.

서버 없이 파일을 메신저로 주고받으며 여러 사람이 한 업무를 나눠 처리합니다. 업무 화면 오른쪽의 **[협업·인수인계]** 에서 시작합니다.

**관리자**
1. 내 이름과 함께 일하는 사람(이름·소속)을 한 번 등록합니다.
2. 단계별로 담당자와 마감일을 고르고 **[요청 파일 만들기]** → 만든 파일 하나를 메신저로 담당자 모두에게 보냅니다.
3. 담당자의 **회신 파일**을 받으면 [가져오기]로 엽니다 → 맡긴 단계만 원래 업무에 자동으로 합쳐집니다.

**담당자**
1. 받은 요청 파일을 [가져오기]로 열고 **본인 이름**을 고릅니다.
2. ★ 표시된 내 단계만 체크·조치결과·조치결과 첨부를 입력합니다. 처음 열면 내 단계만 보입니다. 체크리스트 제목 줄의 [★ 내 담당] [전체 단계 n]으로 바꿔 볼 수 있고(관리자 화면의 보기 선택과 같은 자리), 앞 단계 조치결과 등은 [전체 단계]로 보며, 다른 단계는 흐리게(보기 전용) 보입니다. 고른 보기는 업무마다 기억합니다.
3. **[관리자에게 회신]** → 회신 파일을 메신저로 관리자에게 보냅니다. 고칠 게 생기면 다시 회신하면 됩니다(2차 회신).

**알아 둘 점**
- 회신 파일에는 맡은 단계의 체크·해당 없음·조치결과·조치결과 첨부만 담깁니다 (법령·서식은 담지 않음).
- 담당자의 조치결과 첨부는 합계 **10MB**까지입니다 (회신 파일은 약 13~14MB — 메신저 한도 20MB 안). 사진은 자동으로 줄여 첨부합니다.
- 조치결과 첨부(직접 올린 것·회신으로 받은 것)는 이름을 누르면 프로그램 안 미리보기 창으로 엽니다(HWPX·DOCX·PDF·사진·텍스트). 줄마다 👁 미리보기·⬇ 내려받기가 있고 사진은 작은 썸네일로 보입니다. 미리보기가 안 되는 형식(엑셀·HWP 등)은 내려받습니다. 첨부가 4개 이상이면 목록 칸 안에서만 스크롤되고(3줄 높이), 제목에 첨부 개수가 보입니다. 서식 탭의 파일 목록도 같은 모양(▲▼ 순서 바꾸기·연결 해제 포함)이지만, 개수 제한 없이 창 크기만큼 보이고(창을 크게 하면 더 많이) 「+ 파일 첨부」·「서식·문서함에서 연결」 버튼(조치결과 탭과 같은 모양)은 창 맨 아래에 고정됩니다.
- **창 크게(전체화면)**: 항목 창(조치결과·업무팁·서식), 파일 미리보기 창, 업무 분담 창, 업무 관리 창 모두 오른쪽 위 ✕ 왼쪽의 네 모서리 버튼으로 화면 가득 키웁니다. 제목 줄을 두 번 눌러도 되고, 고른 크기는 창마다 기억합니다.
- **저장 알림**: 항목 창(조치결과·업무팁·서식·첨부)을 닫을 때 바뀐 게 있으면 「○○ 변경 사항이 저장되었습니다」가 한 번 뜹니다. 열어 보기만 했으면 뜨지 않습니다. Esc로 닫아도 적어 둔 조치결과·업무팁은 저장됩니다.
- **안내 표시**: 안내 상자·창 위 안내 줄·협업 안내·알림이 한 디자인(옅은 바탕 + 얇은 테두리 + 선 아이콘)입니다. 색은 안내 파랑·주의 주황·위험 빨강·완료 초록·팁 보라·잠금 회색.
- 다른 사람에게 맡긴 단계는 잠겨서 고칠 수 없습니다. 같은 회신을 두 번 열거나, 맡기지 않은 사람의 회신은 반영하지 않습니다.
- **마감 관리**: 관리자 협업 창 맨 위의 **회신 현황판**에서 누가 늦고 있는지 신호등 색(🔴 기한 지남 · 🟡 임박 · 🟢 여유 · ✅ 반영)으로 봅니다. **[재촉 문구 복사]** 로 기한에 맞는 문구를 복사해 메신저에 붙여 넣을 수 있습니다. 마감일을 정할 때 전체 마감보다 늦거나, 단계 순서와 어긋나거나, 주말·공휴일이면 경고합니다.
- **중간 회신**: 담당자는 다 끝나지 않아도 [중간 회신]으로 진행 상황을 보낼 수 있습니다. 관리자 쪽에서는 진행 상황만 반영되고 단계는 계속 회신 대기입니다. 다 끝나면 [최종 회신]을 보냅니다.
- 담당자 화면의 진행률은 **내 담당 단계 기준**이고, 업무 마감일은 **본인 마감일**로 보입니다.
- **인수인계**: [협업·인수인계] → 담당자 변경에서 업무 전체와 관리자 자격을 새 담당자에게 넘깁니다. 넘긴 PC의 업무는 보기 전용이 됩니다.
- **업무 여권**: 요청·회신·인수인계 기록이 남고, 기록이 중간에 바뀌면 알려 줍니다 (실수·혼동 방지용이며 서명 같은 보안 인증은 아님).
- 함께 일하는 모든 사람이 **v1.3.0 이상**을 써야 합니다. 예전 버전으로 요청 파일을 열면 일반 업무로 들어옵니다.

## 새 버전 배포 방법

HTML 안의 `APP_VERSION`, `APP_RELEASE_DATE`, `APP_RELEASE_NOTES` 세 가지만 고칩니다(두 파일 모두).

- 기능 추가: 가운데 숫자를 올림 (예: 1.1.0 → 1.2.0)
- 오류 수정만: 끝 숫자를 올림 (예: 1.1.0 → 1.1.1)

예전 버전 파일을 열면 프로그램이 자동으로 경고를 띄웁니다.

## 내부망 PC 점검

기관 PC는 보안 정책 때문에 폴더 저장이 막혀 있거나, 브라우저를 끌 때 사용 기록(업무 자료 포함)이 지워지도록 설정돼 있을 수 있습니다.
`내부망_점검.html`을 평소 쓰는 브라우저로 열고 버튼을 차례로 누르면 아래 항목을 확인해 결과를 보여줍니다. 인터넷 연결은 쓰지 않습니다.

1. 브라우저가 폴더 저장 기능을 지원하는지
2. 저장 한도·사용량·영구 보존(자동 삭제 방지) 승인 여부
3. 브라우저를 완전히 껐다 켜도 자료가 남는지 (한 번 껐다 켠 뒤 다시 열어 확인)
4. 파일 저장 창으로 저장되는지
5. 고른 폴더에 쓰고 다시 읽었을 때 내용이 같은지 (다르면 문서 보안 프로그램의 자동 암호화 의심)
6. 다시 열었을 때 폴더 허용이 유지되는지

점검이 끝나면 [결과 복사]로 결과를 전달해 주세요. 시험 파일은 점검 직후 자동으로 지워집니다.
